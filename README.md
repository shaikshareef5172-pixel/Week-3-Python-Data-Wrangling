# Week 3 - Python & Data Wrangling

## Project Overview

This project focuses on cleaning and analyzing a messy dataset using Python and Pandas.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed

- Loaded CSV dataset using Pandas
- Inspected the dataset
- Checked data types
- Identified missing values
- Handled missing values
- Checked and removed duplicate records
- Converted the Date column
- Filtered rows
- Created new columns
- Performed basic statistical analysis
- Created data visualizations
- Exported the cleaned dataset

## Files

- `data/data.csv` - Original dataset
- `cleaned_data.csv` - Cleaned dataset
- `week3_data_cleaning.ipynb` - Python analysis notebook

## Conclusion

The dataset was cleaned and analyzed using Python and Pandas. Missing values were handled, new analytical columns were created, selected records were filtered, and visualizations were generated to understand the data.
